# The OD Passcode

![Difficulty](https://img.shields.io/badge/Difficulty-Medium-yellow)

## Problem

Sindhusree the President of Geeks for Geeks club Ramapuram has completed her work and is ready to apply for an OD. However, the OD portal generates a passcode from her name. The passcode is generated by:

- Converting all characters to lowercase.
- Removing every vowel (a, e, i, o, u).
- Keeping the remaining characters in their original order.

Your task is to generate the final OD passcode.

 **Input Format** 

A single string S containing only uppercase English letters.

 **Constraints** 

- 1 ≤ |S| ≤ 10^5
- S contains only uppercase English letters.
- It is possible that all characters are vowels.

 **Output Format** 

Print the OD passcode obtained after removing all vowels and converting the remaining characters to lowercase.

 **Sample Input 0** 

```
SINDHUSREE

```

 **Sample Output 0** 

```
sndhsr

```

## Solution

**Language:** C++  
**Runtime:** N/A  
**Memory:** N/A  
**Submitted:** 2026-08-22T12:37:21.860Z  

```cpp
#include <cmath>
#include <cstdio>
#include <vector>
#include <iostream>
#include <algorithm>
using namespace std;


int main() {
    string s;
    cin >>s;
    for(char c : s){
        if (c != 'A' && c != 'E' && c!='I' && c!='O' && c!='U'){
            cout << (char)tolower(c);
        }
        
    }  
    return 0;
}

```
